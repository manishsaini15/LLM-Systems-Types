# LLM System Types (Notebook)

This repository contains a Jupyter Notebook explaining and demonstrating different categories of LLM-based systems based on reasoning and interaction steps.

## Covered LLM System Types

1. Single-shot (one-pass) systems  
2. Multi-step chaining (pipeline-style) systems  
3. Few-shot / In-context learning systems  
4. Chain-of-Thought (CoT) systems  
5. Multi-turn conversational systems  
6. Tool-augmented LLM systems  
7. Retrieval-Augmented Generation (RAG) systems  
8. Agentic (autonomous) LLM systems  
9. Multi-agent LLM systems  

## Notebook Includes
- Explanation of each system type
- Code examples / pseudo pipelines
- Practical comparison between approaches
